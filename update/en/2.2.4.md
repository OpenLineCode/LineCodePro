# v2.2.4

### Model endpoints

- **Pasted endpoints are repaired before use** - a base URL without a scheme now defaults to `http://` for a local or LAN host and `https://` otherwise, full-width punctuation from a CJK keyboard is folded back to ASCII, invisible characters are dropped and trailing slashes are removed, so `kilocode.ai/api/openrouter` is called instead of being rejected.
- **Plain HTTP follows the app policy** - model endpoints accept `http://` on loopback, emulator, private/LAN and link-local hosts, exactly like MCP servers; enabling **Ignore HTTP restrictions** in the security settings also admits a public host.
- **The failure names the reason and the address** - an unusable endpoint no longer reports only "unsupported endpoint": it says what is wrong, for example `malformed base URL: https://api.example.com/v 1` or `plain http base URL is only allowed for local or LAN hosts`, with credentials and query strings stripped from the logged address.
- **The provider form validates the address** - saving a provider or fetching its model list refuses a URL that is not an absolute HTTP(S) address and explains why, instead of asking for "required fields".
- **Configuration failures are neither retried nor masked** - an invalid endpoint or a rejected credential now fails once with its own error code. It used to be retried three times and then reported as `UNKNOWN`, and the chat notice only said "AI generation failed"; a turn that fails this way now points at the provider base URL.
