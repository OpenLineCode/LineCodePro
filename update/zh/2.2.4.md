# v2.2.4

### 模型接口地址

- **粘贴的地址会先被修复** - 缺少协议的地址现在按主机自动补全：本机或局域网地址补 `http://`，其他地址补 `https://`；中文输入法带出的全角标点会折回 ASCII，零宽字符被丢弃，尾部斜杠被去掉，`kilocode.ai/api/openrouter` 这类地址会真正发出请求而不是被拒绝。
- **明文 HTTP 与应用策略一致** - 模型接口地址现在和 MCP 服务一样，允许回环、模拟器、私有/局域网与链路本地地址使用 `http://`；在安全设置里开启「无视 HTTP 限制」后，公网地址同样可以使用。
- **失败信息会说明原因和地址** - 地址不可用时不再只报一句 `unsupported endpoint`，而是给出具体原因，例如 `malformed base URL: https://api.example.com/v 1`；写入日志的地址会去掉凭据与 query。
- **提供商表单会校验地址** - 保存提供商或拉取模型列表时，非绝对 HTTP(S) 地址会被拦下并说明原因，不再笼统提示「请填写必填项」。
- **配置类错误不再重试、不再被降级** - 地址不可用或凭据被拒现在只请求一次并保留原有错误码；此前会重试三次后被报成 `UNKNOWN`，聊天提示也只有「AI 生成失败」。现在这类失败会直接指向该模型所属提供商的基础地址。
